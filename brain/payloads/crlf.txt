# Detection: successful injection puts your Set-Cookie / X-Injection-Test into the response headers.

# ── Placement matters — try these injection SPOTS ─────────
# - end of URL path (before query string)  →  /page%0d%0aSet-Cookie:...
# - inside a query value                   →  ?next=home%0d%0aSet-Cookie:...
# - inside Host / Referer / User-Agent headers via a proxy
# - inside a URL used as a redirect target (login?returnTo=...)

# ── Escalations ────────────────────────────────────────────

# CRLF → open-redirect via Location  (phishing chain)
